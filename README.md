# AutoLogHunter-Python-Scripting-
A script that parses system or web logs, identifies suspicious activity (e.g., brute-force login attempts, port scanning), and outputs alerts to console or file.

**AutoLogHunter** scans system log files (default: `/var/log/auth.log`) to identify and report suspicious login activity, including:

- Failed SSH login attempts
- Potential brute-force behavior
- Suspicious IP addresses

This tool is designed to support junior SOC analysts, cybersecurity students, and Linux enthusiasts who want to build alert logic using real log data.
