# AutoLogHunter-Python-Scripting-
This is my first independant cyber project and i created it to improve my understanding my and skillset as a cyber defender. This scripts purpose is to parse system logs and identify suspicious activity (e.g., brute-force login attempts, port scanning), and outputs alerts to console or file.

**AutoLogHunter** scans system log files (default: `/var/log/auth.log`) to identify and report suspicious login activity, including:

- Failed SSH login attempts
- Potential brute-force behavior
- Suspicious IP addresses
